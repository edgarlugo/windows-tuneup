## Not included

What was evaluated and left out of the catalog, with the reason. What is never applied, not even with `-Include`, is listed in [blacklist.md](blacklist.md).

### Apps that cannot be reinstalled on undo

Undo reinstalls an app with winget from the Microsoft Store. For these apps winget does not find the product (code 0x8A150014, checked on 2026-10-01), so removing them could not be undone: they are left out.

- **Microsoft Solitaire Collection** (`Microsoft.MicrosoftSolitaireCollection`): winget does not resolve 9WZDNCRFHWD2.
- **Microsoft Tips** (`Microsoft.Getstarted`): winget does not resolve 9WZDNCRDTBJJ.
- **People** (`Microsoft.People`): winget does not resolve 9NBLGGH10PG8.
- **Windows Maps** (`Microsoft.WindowsMaps`): winget does not resolve 9WZDNCRDTBVB.
- **3D Viewer** (`Microsoft.Microsoft3DViewer`): winget does not resolve 9NBLGGH42THS.
- **Paint 3D** (`Microsoft.MSPaint`): winget does not resolve 9NBLGGH5FV99 (it is not the current Paint).
- **Print 3D** (`Microsoft.Print3D`): winget does not resolve 9PBPCH085S3S.
- **3D Builder** (`Microsoft.3DBuilder`): winget does not resolve 9WZDNCRFJ3T6.
- **Microsoft Wallet** (`Microsoft.Wallet`): winget does not resolve 9NBLGGH52CKV.
- **Mobile Plans** (`Microsoft.OneConnect`): winget does not resolve 9NBLGGH5PNB1.
- **MSN Sports** (`Microsoft.BingSports`): winget does not resolve 9WZDNCRFHVH4.
- **Translator** (`Microsoft.BingTranslator`): winget does not resolve 9WZDNCRFJ3PG.
- **Xbox Game Bar Plugin** (`Microsoft.XboxGameOverlay`): winget does not resolve 9NBLGGH537C2.
- **Xbox Console Companion** (`Microsoft.XboxApp`): winget does not resolve 9WZDNCRFJBD8.
- **Cortana** (`Microsoft.549981C3F5F10`): winget does not resolve 9NFFX4SZZ23L; Cortana no longer exists in Windows 11.

### Apps without a Store product

They come with Windows or Windows Update and have no Store id to reinstall them with, or it could not be checked which package their id installs.

- **Microsoft 365 Companions** (`Microsoft.M365Companions`): No Store product.
- **AI Hub** (`Microsoft.Windows.AIHub`): No Store product.
- **Cross Device Experience Host** (`MicrosoftWindows.CrossDevice`): System package that goes with Phone Link; no Store product.
- **Skype** (`Microsoft.SkypeApp`): It no longer has a Store product.
- **Microsoft Teams (classic personal)** (`MicrosoftTeams`): No Store product; the new Teams (MSTeams) is in the catalog.
- **Microsoft Copilot (XP9CXNGPPJ97XX)**: winget resolves it, but it could not be checked which Appx package it installs; the Windows Copilot app (9NHT9RB2F4HD) is included.

### Apps that are never removed

Other apps depend on them, Windows does not let them be removed, or they keep the user's data inside the app.

- **Microsoft Store** (`Microsoft.WindowsStore`): Undoing any app depends on it. Removing it would be a separate option with a warning; it does not exist today.
- **App Installer (winget)** (`Microsoft.DesktopAppInstaller`): It is winget: without it there is no undo. Windows does not let it be removed.
- **Windows Security** (`Microsoft.SecHealthUI`): The Defender interface; Windows does not let it be removed.
- **Xbox Identity Provider, Xbox TCUI, Xbox Speech To Text Overlay, Game Callable UI**: The Store, Game Pass and games use them to sign in.
- **Photos, Calculator, Notepad, Paint, Snipping Tool, Camera, Terminal**: Basic and default tools; they are not junk.
- **Sticky Notes, Journal, Whiteboard, OneNote**: They keep the user's notes inside the app: removing them deletes those notes.
- **Microsoft Edge, WebView2, codecs and frameworks (Microsoft.NET.*, Microsoft.VCLibs.*, Microsoft.UI.Xaml.*)**: Other apps depend on them.

### Xbox services

They were in the catalog and were removed: they are already Manual and Windows starts them by itself when a game needs them, so disabling them saves nothing and breaks the Xbox and Game Pass sign-in. The Xbox app and task can be removed (the `gaming` profile keeps them).

- **XblGameSave**: Xbox Live game saves; it is already Manual.
- **XblAuthManager**: Xbox Live sign-in; disabling it stops the games that use it from signing in.
- **XboxNetApiSvc**: Xbox Live networking for multiplayer; it is already Manual.

### Policies that Windows Home ignores

Windows Home ignores many group policies. The catalog tweaks that are policies declare the editions where Microsoft documents them, and the plan shows them as "does not apply" on Home (the list is above, in "Tweaks that do not apply on Home"). What follows was left out because on Home there is no way that works and can be undone.

- **Minimum telemetry by policy on Home**: AllowTelemetry in the policies does not apply on Home; the only thing that stops the upload there is the DiagTrack service (services.diagtrack, which asks first).
- **Consumer content and Microsoft 365 cards on Home and Pro**: DisableWindowsConsumerFeatures and DisableConsumerAccountStateContent only apply to Enterprise and Education; on Home and Pro the user ads tweaks cover what can be covered.
- **Widgets on Home (TaskbarDa)**: Windows blocks writing that value from PowerShell (UCPD); the policy only applies on Pro and later.
- **Modern standby network and Delivery Optimization on Home**: Without a policy that Home honors they need other hives or power subgroups that the engine does not support.

### Dropped actions

They were evaluated as actions of their own and dropped because it could not be verified, read-only, that they do what they promise and can be undone.

- **power-mode-overlay: "Best performance" power mode on AC**: It is an overlay of the power plan that only an undocumented Windows function changes (PowerSetActiveOverlayScheme); it is unknown whether it changes AC and DC together or whether writing the registry takes effect live.
- **dev-defender-performance-mode: Defender performance mode for Dev Drive**: Microsoft turns it on by default on a trusted Dev Drive, and the value read on a machine without a Dev Drive contradicts that documentation; it cannot be checked without a Dev Drive, and it touches Defender.

### Tweaks that could not be verified

Left out until it is checked that they do what they promise and that they can be undone.

- **Taskbar animations (TaskbarAnimations)**: No evidence of an effect on Windows 11.
- **AllowGameDVR policy**: Microsoft: it only applies to Windows 10 desktop; the user values of Game DVR already cover the goal.
- **Cloud search (IsMSACloudSearchEnabled, IsAADCloudSearchEnabled)**: Community sources only; the work-account one breaks OneDrive and Outlook results in search.
- **InventorySvc and PcaSvc services**: No Microsoft guidance for client machines; the first one feeds feature updates.

### Waiting for an engine capability

They would be useful, but the engine cannot apply and undo them exactly yet.

- **Visual effects (UserPreferencesMask)**: It is a binary value and the catalog does not accept Binary values yet.
- **Classic context menu of Windows 11**: It uses the default value of a key, which the registry handler does not support; it is also a preference.
- **Hibernation, startup apps, smaller indexing, printers**: They need their own action with a question; they stay as ideas.
